# 🧬 DNA Similarity Analyzer

A C++ application that compares two DNA sequences using the **Longest Common Subsequence (LCS)** algorithm.

## Features
- Compare two DNA sequences
- Find LCS length
- Calculate similarity percentage
- Dynamic Programming approach

## Algorithm
**Longest Common Subsequence (LCS)**

- Time Complexity: O(n × m)
- Space Complexity: O(n × m)

## Sample Input

DNA 1: ATGCTGA
DNA 2: ATCTGGA

## Sample Output

LCS Length: 6
Similarity: 85.71%

## Tech Stack
- C++
- Dynamic Programming
- Code::Blocks
